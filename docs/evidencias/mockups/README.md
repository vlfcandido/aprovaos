Regras que os arquivos respeitam e que valem para qualquer mockup futuro:
- Todo número é ilustrativo e a página diz isso (selo no topo). Não há afirmação sobre concorrente com nome.
- Conteúdo jurídico dos exemplos é real e citado (CF art. 71 e 49; Súmula 347/STF superada pelo MS 35.410 de 2023 — este último como síntese, não citação literal).
- "Pedido da Ana" marca o que entrou depois da entrevista; serve para a próxima entrevistada ver o que outra concurseira pediu.
- Arquivo único, sem dependência externa além das fontes do Google Fonts; abre com duplo clique. Grifos e anotações ficam no `localStorage` do navegador de quem abre.
