# Fase 4 — evidências do ciclo RED→GREEN→REFACTOR das 7 skills (17/09/2026)
> O que é: o registro do teste de cada skill do Motor com Haiku (modelo menor, ADR-0014): o que o modelo fez **sem** a skill (baseline), o que fez **com** ela, e o que precisou ser reescrito. Quando ler: ao editar qualquer skill em `.claude/skills/` (a regra é: editar = retestar) ou ao desconfiar que uma skill "não pega" num modelo menor.

Método: `superpowers:writing-skills`. Cada linha abaixo = um cenário realista com os fixtures de `fixtures/` (edital fictício de assessor de gabinete em Cascavel, trecho de prova Cebraspe C/E com gabarito e anulação, dossiê de controle externo com fontes, 14 dias de eventos agregados).
